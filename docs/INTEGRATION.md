# Runtime contracts

All gameplay is native runtime C++. Agent-owned headers are OBPlayerCharacter.h, OBEnemyCharacter.h (+ OBEnemyProjectile), OBUI.h (AOBPlayerController, AOBHUD). Root owns OBCore.h/cpp (save/settings, mission director, game mode, doors, interactables). Agent implementations must read this file and OBCore.h before integration.

Player public fields: Health, MagazineAmmo, ReserveAmmo, bWeaponOwned, bReloading, bAiming, bDead, InteractionProgress, InteractionPrompt, LastHitTime. Methods RestoreLoadout(bool,int,int), CancelActions(), AddHealth(float), AddAmmo(int), IsGameplayActive(), AcquireWeapon(), GetMuzzleLocation(), GetAimDirection(). Native input via SetupPlayerInputComponent uses action names Fire, Aim, Sprint, Jump, Reload, Interact; axes MoveForward, MoveRight, Turn, LookUp. Player calls mission FindInteraction(this), TryInteract(this,target), UpdateHold(this,target,delta), CancelHold(). Main coordinator owns interaction validation/progress. Player can call DamagePlayer(float,FVector) for damage feedback. Director handles death via PlayerDied(). Root can adjust API at integration.

Enemy editable fields: StableId (FName), EncounterId (int32 1..6), bHeavy (bool). Methods Activate(), SetResolved(), IsDead(). Enemy calls director TryAcquireAttackSlot(this), ReleaseAttackSlot(this), ResolveEnemy(EncounterId,StableId), IsCombatAllowed(). Enemy never registers as resolved on ordinary Destroy/unload. Director iterates placed enemies once and owns encounter activation. Dormant enemies hidden and collision disabled until activated. No runtime spawn required, except projectiles/effects. Every enemy must use AIController and navmesh with perception 0.2s. Player hits via TakeDamage standard UE API. Projectile uses swept collision.

UI: AOBPlayerController in OBUI.h. Method ShowScreen(FName) sets Main, Pause, Dead, Complete, EndingPause, Settings, Controls; HideScreen() resumes input; IsMenuOpen(); MenuScreen public FName. Tick while paused. HUD calls GI NewMission(), ContinueMission(), ReturnToMenu(); director RetryCheckpoint(), BeginEnding(), CompleteMission(); controller handles pause and input restoration. Settings fields in UOBSettings. HUD rendering should be Canvas/Hitboxes with keyboard support to avoid brittle widget asset authoring. Root handles save/menu integration.

Map native actor classes from OBCore.h: OBMissionDirector (one), OBDoor DoorId(int 0..6), OBInteractable Kind enum (Weapon,AmmoStation,Terminal,Pod,Medical,Ammo), StableId FName, Zone int (1..6). OBZoneTrigger Zone(int 1..6), TriggerExtent FVector, bCheckpoint bool. Doors are placed at center bottom? Root door actor origin is center of panel, default panel 60x300x320 cm, door opens +Z 340cm. Interactables use procedural appearance in native construction, origin on floor. Zone triggers box defaults extent (120,200,150) origin center at Z150.

Level builds real saved /Game/OrbitBreakout/Maps/L_EmergencyDeparture. Use actor folder OB_Generated and tag OB_GENERATED. Six connected zones along +X; exact coordinates level author chooses/document in layout manifest. Root progression triggers: Zone 2 E01; Zone 3 commits CP01 at first checkpoint threshold then E02 on next regular trigger; Zone4 no encounter until terminal; Zone5 commits CP02 on threshold then E05 next; Zone6 E06. CP starts provided in director editable FVector StartLocation, CargoCheckpointLocation, ReactorCheckpointLocation (center of character capsule, z100). One PlayerStart same start. Gate IDs:0 cell,1 weapon exit,2 cargo entry,3 security entry,4 reactor entry,5 escape bay,6 pod hatch. Aim cardinal: initial camera/player +X.

Sounds paths /Game/OrbitBreakout/Audio/S_<Name>, material paths /Game/OrbitBreakout/Materials/M_<Name>. Level author establishes names; runtime primitive characters may use basic engine shapes and dynamic material /Engine/BasicShapes/BasicShapeMaterial. Use shared imported sounds, not required to exist at compile. Original synthesis authorized. No external assets or uploads.
